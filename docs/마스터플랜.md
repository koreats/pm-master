# PM System 2025 마스터 플랜

## 🎯 프로젝트 개요

### 핵심 목표
- **미션**: 개인 및 소규모 팀(1~5명)을 위한 초경량 프로젝트 관리 도구 개발
- **비전**: 미니멀하고 직관적이며 실시간 협업이 가능한 차세대 PM 도구
- **핵심 가치**: 단순함, 효율성, 협업, 자동화

### 기술 스택 및 아키텍처
```yaml
Frontend:
  - Next.js 15.1.0 (App Router + Turbopack)
  - TypeScript 5.6.3
  - Tailwind CSS 3.4.1
  - Radix UI + shadcn/ui
  - Framer Motion

Backend:
  - Supabase (PostgreSQL 15 + Auth + Realtime + Storage)
  - Server Actions (Next.js 15)

State Management:
  - TanStack Query v5 (서버 상태)
  - Zustand v4 (클라이언트 상태)

Testing:
  - Jest + React Testing Library
  - Playwright (E2E)

Deployment:
  - Vercel (Frontend)
  - Supabase (Backend)
```

### 프로젝트 특징
- **3계층 구조**: Goals → Projects → Tasks
- **6가지 뷰**: Table, Kanban, Calendar, Timeline, Gallery, List
- **실시간 협업**: 다중 사용자 동시 편집, 충돌 해결
- **자동화 엔진**: 트리거 기반 워크플로우
- **PWA 지원**: 오프라인 작업, 푸시 알림
- **접근성**: WCAG 2.1 AA 준수
