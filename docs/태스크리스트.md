# PM System 2025 개발 태스크 리스트

## 프로젝트 개요
- **프로젝트명**: PM System 2025
- **목적**: 개인 및 소규모 팀(1~5명)을 위한 초경량 프로젝트 관리 도구
- **기술 스택**: Next.js 15.1.0 + Supabase + Tailwind CSS + Radix UI + shadcn/ui
- **아키텍처**: 3계층 구조 (Goals → Projects → Tasks)
- **주요 기능**: 6가지 뷰, 실시간 협업, 자동화, PWA 지원

## T-001 프로젝트 초기 설정

### 요구사항
- Next.js 15.1.0 프로젝트 초기화 및 기본 설정
- Supabase 프로젝트 생성 및 환경 설정
- 개발 환경 구성 및 코드 품질 도구 설정
- 기본 폴더 구조 및 라우팅 설정

### 구현 세부사항
- **기술 스택 설정**
  - Next.js 15.1.0 (App Router + Turbopack)
  - TypeScript 5.6.3
  - Tailwind CSS 3.4.1
  - ESLint + Prettier 설정
- **Supabase 설정**
  - 프로젝트 생성 및 환경 변수 설정
  - 클라이언트/서버 설정 파일 생성
  - 미들웨어 인증 설정
- **폴더 구조**
  ```
  app/
    ├── api/          # API 라우트
    ├── auth/         # 인증 페이지
    ├── dashboard/    # 대시보드
    └── (기능별)/     # 기능별 그룹
  components/
    ├── ui/           # 기본 UI 컴포넌트
    ├── features/     # 기능별 컴포넌트
    └── layouts/      # 레이아웃 컴포넌트
  lib/
    ├── supabase/     # Supabase 클라이언트
    ├── hooks/        # 커스텀 훅
    └── stores/       # Zustand 스토어
  ```

### 테스팅 전략
- 프로젝트 빌드 테스트 (`npm run build`)
- TypeScript 타입 체크 (`npm run type-check`)
- ESLint 및 Prettier 실행 확인

### 서브태스크
1. Next.js 15.1.0 프로젝트 생성 및 종속성 설치
2. TypeScript 및 개발 도구 설정 (ESLint, Prettier, Husky)
3. Tailwind CSS 및 PostCSS 설정
4. Supabase 프로젝트 생성 및 로컬 환경 설정
5. 폴더 구조 및 기본 라우팅 설정
6. 환경 변수 및 설정 파일 구성
7. 개발 서버 및 빌드 프로세스 검증

## T-002 인증 및 권한 시스템

### 요구사항

- 이메일/비밀번호 로그인 및 회원가입
- 소셜 로그인 (Google, GitHub) 
- 역할 기반 권한 관리 (개인/팀원/관리자)
- 세션 관리 및 보안 설정

### 구현 세부사항
- **인증 플로우**
  - 회원가입: 이메일 인증 필수
  - 로그인: 이메일/비밀번호 + 소셜 로그인
  - 비밀번호 재설정: 이메일 기반
- **권한 시스템**
  - 개인 워크스페이스: 모든 권한

- **보안 설정**
  - bcrypt 암호화
  - JWT 토큰 관리
  - CSRF 보호
  - Rate limiting

### 테스팅 전략

- 권한별 접근 제어 테스트

- 소셜 로그인 통합 테스트

- 데이터 마이그레이션 및 시드 데이터

### 구현 세부사항
- **핵심 테이블 구조**
  ```sql
  users (인증 사용자)
  teams (팀/워크스페이스)  
  team_members (팀 멤버십)
  goals (목표)
  projects (프로젝트)
  tasks (작업)
  comments (댓글)
  attachments (첨부파일)
  automations (자동화)
  ```
- **RLS 정책**
  - 사용자별 데이터 격리
  - 팀 멤버십 기반 접근 제어
  - 역할별 권한 관리
- **실시간 설정**
  - 테이블별 Publication 설정
  - 변경 사항 브로드캐스트

### 테스팅 전략
- 스키마 마이그레이션 테스트
- RLS 정책 검증
- 실시간 기능 동기화 테스트
- 데이터 무결성 검증

### 서브태스크
1. ERD 설계 및 테이블 관계 정의
2. 기본 스키마 마이그레이션 작성
3. 사용자 및 팀 관련 테이블 생성
4. Goals, Projects, Tasks 테이블 생성
